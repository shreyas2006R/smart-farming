GOOD TO KNOWFAQ

Clear expectations.
Better farming.

A few notes about what the website demonstrates today and what a connected farm system would still need.

Is the dashboard connected to real sensors?＋

No. This is an interactive frontend prototype with illustrative values. Live readings require installed hardware, a data connection, and a backend or IoT service.

Can I control a real pump from this page?＋

No. The pump switch is a visual simulation only. Secure authentication, backend commands, hardware interlocks, and professionally checked electrical protection are required before live control.

Are crop prices and fertilizer advice live?＋

No live agricultural-market feed or agronomy service is configured. Current prices need a reliable licensed source. Recommendations should account for crop, soil, growth stage, region and local agricultural guidance.

Can this website run on GitHub Pages?＋

Yes. The frontend uses static HTML, CSS and JavaScript. GitHub Actions can publish it without a separate application server.
